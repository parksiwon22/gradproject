# LightGBM 72시간 SMP 예측모델 성능 개선 및 GitHub 업로드

## 0. 작업 목표

현재 구현된 LightGBM 72시간 육지 SMP 예측모델을 기반으로 성능 개선 실험을 진행한다.

**기존 모델, 데이터, 예측 결과 및 보고서는 수정하거나 삭제하지 않는다.**

기존 모델 폴더 안에 업그레이드 전용 하위 폴더를 새로 만들고, 새로운 코드, 학습 모델, 예측 결과, 그래프, 보고서를 모두 그 폴더에 저장한다.

작업 완료 후 현재 GitHub 저장소에 별도 브랜치를 생성하여 커밋하고 push한다.

이번 작업은 72시간 LightGBM 모델 하나만 대상으로 한다. 다른 모델 계열은 수정하지 않는다.

## 3. 반드시 유지할 연구 조건

- 목표변수: 육지 시간별 SMP
- 단위: 원/kWh
- 시간대: Asia/Seoul
- 예측 기준시각: D일 23:00
- 예측 범위: D+1~D+3 총 72시간
- 공통 입력 그룹: 기존 12개 그룹
- 데이터셋: 기존 확정 공통 데이터셋 재사용
- 미래 실측값 사용 금지
- 별도의 신규 API 수집 또는 입력변수 추가 금지
- 다른 세 모델의 데이터 및 결과 변경 금지

학습 및 평가 기간:

| 구분 | 기간 |
|---|---|
| Train | 2023-01-01~2024-12-31 |
| Validation | 2025-01-01~2025-06-30 |
| Final Test | 2025-07-01~2025-12-31 |

기존과 동일한 평가 발행일, 대상시간 및 데이터 버전을 사용한다.

기존 결과와 다른 평가 행을 사용했다면 성능 개선으로 단순 비교하지 않는다.

## 4. 실측자료 72시간 지연 규칙 유지

공표시각을 확인하기 어려운 실측 입력은 기존 연구 가정을 유지한다.

`observed_cutoff = forecast_origin - 72 hours`

예를 들어 2025년 7월 1일 23시에 예측한다면, 실측 입력에는 2025년 6월 28일 23시까지의 이용 가능한 과거 자료만 사용한다.

실제 관측 구간이 마감시각 이전에 완결되었는지도 확인한다.

D+1, D+2, D+3 모두 동일한 실측 입력 마감시각을 적용한다.

각 예측 대상시간에서 72시간을 빼는 방식은 사용하지 않는다.

적용 대상:

- 실제 전력수요
- 발전원별 발전량
- 태양광 및 풍력 발전량
- 공급예비력 및 예비율
- ASOS 기상 관측

2번 하루전 수요예측은 기존 과거 예측 이력 규칙을 유지한다.

12번 중기예보는 실제 예보 발표시각이 있으므로 해당 발표시각을 이용한다.

달력과 공휴일에는 실측 지연 규칙을 적용하지 않는다.

FRED 국제가격은 기존 D-2 vintage 규칙을 유지한다.

국내 LNG는 기존 동월 단가 제공 조건부 실험 규칙을 유지한다.

이 규칙들은 이번 성능 개선 과정에서 변경하지 않는다.

**72시간 지연은 실제 공표시각을 검증한 결과가 아니라 연구상 가정이라는 점을 유지한다.**

## 5. 개선 작업의 순서

이번 업그레이드에서는 아래 세 가지를 순서대로 수행한다.

**1단계: 기준 예측과 기존 모델 결합 검증**

**2단계: Train+Validation 재학습**

**3단계: D+1, D+2, D+3별 편향 및 성능 분석**

세 단계의 결과를 각각 보존한다.

여러 개선사항을 동시에 적용하여 무엇 때문에 성능이 달라졌는지 알 수 없게 만들지 않는다.

Ablation Study나 새로운 입력변수 선택 실험은 수행하지 않는다.

## 6. 1단계: 기준선 결합 실험

기존 LightGBM 모델이 Final Test에서 단순 기준 예측보다 성능이 나쁘므로, 기준선과의 결합을 우선 검토한다.

사용할 기준선:

1. 기준시각까지 이용 가능한 최근 일별 SMP 패턴
2. 기준시각까지 이용 가능한 전주 동일 시간 SMP 패턴

기존 코드에 구현된 기준선이 있으면 그대로 재사용하되, 미래 실제 SMP를 참조하지 않는지 확인한다.

기준선의 각 참조시각과 이용 가능 여부를 검증한다.

결합 공식:

`final_prediction = α × model_prediction + (1 - α) × baseline_prediction`

여기서 α는 0~1 범위의 결합 가중치다.

다음 후보를 비교한다.

- 기존 LightGBM 단독
- 최근 일별 기준선 단독
- 주간 기준선 단독
- LightGBM + 최근 일별 기준선
- LightGBM + 주간 기준선

가능한 결합 가중치는 Validation MAE를 이용해 선택한다.

예를 들어 α = 0.0, 0.1, 0.2, ..., 1.0을 비교할 수 있다.

α가 0으로 선택되면 기준선만 사용한 결과임을 정확히 표시한다.

**Final Test의 MAE를 보고 결합 가중치를 결정하지 않는다.**

전체 72시간에 동일한 가중치를 적용한 결과를 우선 확인한다.

필요한 경우 Validation 결과만을 이용해 D+1, D+2, D+3별 결합 가중치를 따로 설정하는 방법도 비교한다.

다만 개별 가중치 설정은 Validation에서 충분한 표본과 안정적인 개선 근거가 있는 경우에만 채택한다.

최종 결합 방식과 가중치는 Final Test 실행 전에 확정한다.

## 7. 2단계: Train+Validation 재학습

기존 LightGBM는 Train으로 학습하고 Validation으로 설정을 선택한 뒤, Train 모델을 Final Test에 적용하였다.

이번에는 다음 절차로 변경한다.

1. 기존 Validation 결과와 필요한 시계열 순차 검증을 이용해 하이퍼파라미터 선택
2. 선택된 하이퍼파라미터와 학습 반복 수 확정
3. Train+Validation을 결합한 자료로 새 모델 학습
4. 새 모델 파일 저장
5. Final Test 평가

최종 학습 기간:

`2023-01-01~2025-06-30`

최종 평가 기간:

`2025-07-01~2025-12-31`

Validation을 포함한 재학습 시 표준화, 결측 대체 및 전처리 통계는 해당 재학습 구간에서 다시 적합할 수 있다.

반면 Final Test 자료는 어떠한 전처리 통계나 모델 계수를 적합하는 데 사용하지 않는다.

하이퍼파라미터는 Final Test를 보고 변경하지 않는다.

기준선 결합 가중치 역시 재학습 이전에 검증 자료로 선택한 값을 유지한다.

재학습 후 결합 가중치를 새로 최적화할 필요가 있다면 Train+Validation 내부의 시간순 out-of-fold 예측만을 사용한다.

**Validation과 Final Test를 섞어서 모델을 학습하지 않는다.**

재학습 모델이 기존 모델보다 반드시 좋은 것으로 가정하지 않는다.

## 8. 3단계: 예측거리별 성능 및 편향 분석

다음 항목을 구분해서 분석한다.

- D+1 MAE, RMSE, R²
- D+2 MAE, RMSE, R²
- D+3 MAE, RMSE, R²
- horizon 1~72별 MAE
- 월별 MAE
- 예측값과 실제값의 평균 차이
- 과대예측 및 과소예측 비율
- 예측값의 분산 및 실제값 분산
- 실제 SMP 급등 및 급락 구간의 오차

편향 계산:

`bias = mean(predicted_smp - actual_smp)`

양수이면 과대예측, 음수이면 과소예측으로 해석한다.

특히 Validation MAE와 Final Test MAE가 크게 다른 원인을 조사한다.

입력 결측 대체 비율, 목표 SMP의 가격 분포 변화, 시차 특성 및 예측 범위별 오차를 확인한다.

### 편향 보정

Validation 또는 시간순 out-of-fold 예측으로 확인된 체계적인 편향만 보정 후보로 사용한다.

전체 72시간 동일한 편향 보정과 D+1, D+2, D+3 개별 편향 보정을 비교할 수 있다.

보정값을 Final Test의 실제값으로 산출하는 것은 금지한다.

Validation에서 편향 보정의 개선 효과가 불확실하면 적용하지 않는다.

### 예측거리별 모델 분리

D+1, D+2, D+3을 별도로 학습하는 방식은 선택 가능한 추가 개선안이다.

시간이 지나치게 많이 들거나 Validation 개선 근거가 부족하면 실행하지 않아도 된다.

실행한다면 각 모델에 동일한 공통 입력 데이터와 지연 규칙을 사용한다.

개별 모델 분리 여부 역시 Final Test 성능을 보고 결정하지 않는다.

## 9. 비교 실험 구성

최소한 다음 결과를 구분하여 저장한다.

| 실험명 | 내용 |
|---|---|
| E0 | 기존 LightGBM |
| E1 | 기존 LightGBM와 기준선 결합 |
| E2 | Train+Validation 재학습 LightGBM |
| E3 | 재학습 LightGBM와 검증으로 선택된 기준선 결합 |
| E4 | 필요 시 편향 보정 또는 예측거리별 개선 |

기존 모델은 E0으로 보존한다.

E1~E4는 새로운 업그레이드 결과로 저장한다.

최종 채택 모델은 검증에서 확정한 규칙을 적용한 모델로 정한다.

Final Test 결과가 나쁘더라도 사후적으로 다른 후보로 바꾸지 않는다.

최종 보고서에는 모든 실험의 실제 결과를 표시한다.

## 10. 과거 테스트 결과 사용에 관한 제한

기존 Final Test 결과의 MAE가 이미 확인된 상태다.

따라서 이번 업그레이드는 완전히 새로운 블라인드 테스트라고 주장하지 않는다.

새로운 설정, 결합 가중치, 편향 보정 및 모델 구조는 Validation 또는 그 이전의 시간순 교차검증에서 선택한다.

2025년 하반기 Final Test를 보면서 반복적으로 가중치나 설정을 바꾸지 않는다.

이번 평가 결과는 기존에 확인한 테스트 구간에 대한 재평가라는 점을 보고서에 명시한다.

완전히 독립적인 향후 성능 검증은 추가 기간의 새로운 데이터로 수행해야 한다.

## 11. 최종 성능 평가

모든 실험에 다음 지표를 계산한다.

- MAE
- RMSE
- R²
- D+1 MAE
- D+2 MAE
- D+3 MAE
- horizon 1~72별 MAE
- 목표월별 MAE
- 기준선 대비 개선율
- 발행일별 평가 커버리지

MAE와 RMSE 단위는 원/kWh이다.

평가 시각과 평가 대상 행은 기존 E0과 동일해야 한다.

결측이나 실패로 평가 행이 달라진 경우 반드시 차이를 기록한다.

기존 모델과 개선 모델을 서로 다른 평가 행에서 비교하여 성능 향상으로 표시하지 않는다.

기준선보다 나쁜 경우에도 실제 값을 그대로 보고한다.

## 13. 필수 그래프

다음 그래프를 생성한다.

### 모델별 MAE 비교

기존 LightGBM, 재학습 모델, 기준선 및 결합 모델의 Validation과 Final Test 성능을 구분한다.

### 72시간 SMP 비교

선택된 동일 발행일에 대해 실제 SMP, 기존 LightGBM 예측, 개선 모델 예측을 표시한다.

D+1, D+2, D+3 경계를 나타낸다.

### 월별 MAE

Validation과 Final Test를 구분하고, 월별 기존 및 개선 모델의 오차를 비교한다.

### horizon별 MAE

1~72시간의 기존 및 개선 모델 MAE를 비교한다.

모든 그래프에 단위, 범례, 평가 기간을 표시한다.
