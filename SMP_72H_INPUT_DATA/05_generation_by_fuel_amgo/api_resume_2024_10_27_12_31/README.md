# KPX 발전원별 발전량 API 보완분

- 기간: 2024-10-27~2024-12-31, 66일
- 응답: 66/66일 HTTP 200, API 결과코드 00
- 각 날짜 192행(8개 연료원 × 거래시간 24), 합계 12,672행
- `api_generation_2024_10_27_12_31_addendum.csv`는 API 원본 필드 `tradeNo`, `fuelTpCd`, `tradeYmd`, `amgo`를 보존합니다.
- `daily/`에 날짜별 원응답과 응답 로그를 보존해 실패 시 이미 수집한 날짜를 재사용할 수 있습니다. `acquisition_log.csv`에는 HTTP/API 상태, 행 수, 연료 코드, 응답 SHA-256이 있습니다.
- 인증키는 파일에 저장하지 않았습니다. `amgo` 단위는 독립적으로 확인되지 않아 원래 필드명 그대로 둡니다.
- 이는 5번 전체 2023~2025 완비를 뜻하지 않습니다. 2024년 8월 부분응답 31일은 별도 보완 대상입니다.
- 모델 학습은 수행하지 않았습니다.
