## 보존·변환 범위

- 원본 CSV의 열 이름(앞뒤 공백 포함), 필드 문자열, 원래 행 순서·빈칸·0을 그대로 보존했습니다. 숫자 반올림·0 대체·중복 제거·지역 합산을 하지 않았습니다.
- 다운로드 원본의 한글 인코딩을 UTF-8 BOM으로 변환했습니다.
- 0~5번은 해당 다운로드 파일의 모든 행입니다.
- **6번만 기간 추출본**입니다. 원래 다운로드 파일에는 2017~2023년 자료가 있어서, 이번 요청 범위인 2023년 1~2월 행만 남겼습니다. 그 이전 연도 행은 이 공유본에 포함되지 않습니다. 원래 전체 파일은 로컬 원자료 캐시에 보존합니다.
- 공개 목록의 제목 날짜와 실제 CSV 기간이 일치하지 않는 경우가 있어 위 표는 실제 행 날짜를 기준으로 작성했습니다. 공식 상세항목 제목·파일 ID·원본/공유본 해시·인코딩·조회 시각은 manifest.json에 보존했습니다.
- 파일별 스키마가 다릅니다. 모든 CSV를 열 이름 확인 없이 그대로 이어 붙이지 마세요.

## 육지 풍력 확인

2024·2025년 파일은 다음 조건으로 선택합니다.

```python
import pandas as pd

path = 'shared_datasets/kpx_renewables/renewable_source_1.csv'  # 2024년
# 2025년은 renewable_source_0.csv
raw = pd.read_csv(path, encoding='utf-8-sig', dtype=str, keep_default_na=False)
land_wind = raw.loc[(raw['연료원'] == '풍력') & (raw['지역'] == '육지')]
print(land_wind.head())
```

- 2024년: 풍력의 육지 8,784행, 제주 8,784행.
- 2025년: 풍력의 육지 8,760행, 제주도 8,760행.
- 2023년 12월도 풍력을 육지/제주로 구분합니다.
- 2023년 1~11월은 시도별 풍력 열입니다. 제주 제외 집계 전에 공백의 의미와 지역별 품질을 확인해야 합니다.
- 태양광은 시도별입니다. 태양광의 시도명으로 풍력을 찾으면 `육지` 행을 놓칠 수 있습니다.

단위는 원본 발전량/전력거래량 열의 MWh입니다. 전력시장 참여 발전기의 송전단 거래량이며 PPA·자가용·BTM을 포함한 전국 총발전량이 아닙니다. 자료는 수정정산으로 변경될 수 있습니다. 심야 태양광 수치를 자동으로 0으로 바꾸지 마세요.
