# V20 23:02 공개상태 재조회 보강 — 2026-10-21 준비

## 변경 요약

23:00 실행은 기존 준비본과 직전 공개상태 표본을 확인하는 경로로 유지했다. 실제 예약된 `--warm` 실행이 기준시각 90~180초 뒤에 시작되면(현재 23:02 재시도 슬롯), 발급 직전에 D-2와 D-3 대상일의 KPX API, KPX 일반 공개 페이지, EPSIS 육지 경로를 강제 재조회한다. EPSIS 제주 경로도 기존 collector의 관측으로 함께 기록된다. 모델 추론 및 EV 최적화는 재시도 hot path에 추가하지 않았다.

각 재조회는 기존 V18 collector의 응답 파서와 원본 해시 기록을 사용한다. KPX API의 결과 코드·행 수·파싱 결과, 안전한 오류 요약(예: `API HTTP 403`), 응답 해시, 요청 시작 및 수신시각을 보존한다. API 키와 인증 URL은 저장하거나 로그에 출력하지 않는다. 발급 직전의 불변 감사 파일은 `artifacts/v19/preflight_checks/` 아래 생성되며, 대상일별로 KPX·일반 공개·EPSIS 표본의 상태, 수신시각, 판정시점 기준 나이, 180초 신선도 여부, 공개 여부 판단 사유를 기록한다. 발급 로그에도 감사 요약과 파일 해시를 연결한다.

## 발급 안전 조건

23:02 발급은 재조회 자체가 완료되고, 대상일마다 세 육지 경로 표본이 모두 180초 이내이며, 결과가 오류·부분·기타 불확실 응답이 아니고, 어떤 공개 경로에서도 공식 가격이 확인되지 않았을 때만 기존 발급 검사를 계속한다. 재조회 실패, 표본 미수신 또는 만료, 공식가격 확인, 홈페이지 24시간 0원 응답은 모두 발급을 보류한다. 재조회가 실패한 경우 아직 신선해 보이는 과거 ledger 표본을 fallback으로 사용하지 않도록 별도 gate를 추가했다. 기존 publisher의 all-source gate는 그대로 적용한다.

KPX 정상 `normal_no_data`는 그 API가 해당 시점에 정상 응답했으나 대상 행을 제공하지 않았다는 뜻일 뿐, 보편적 미공개 증명으로 기록하지 않는다. 홈페이지의 24개 0원 응답은 계속 `unverified_all_zero`이며 적격 미관측으로 취급하지 않는다. 공식가격 공개가 불확실한 경우 새 AI 기록은 생성되지 않는다.
