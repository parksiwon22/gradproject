## 시스템 및 전향 검증

- V5, V11/V12 소스·기존 화면·운영 모델을 수정하지 않았다. V13은 별도 서비스와 화면이다.
- 10월 17일 네 모델은 **독립 대상 하루**다. 10월 16일 아침 공개 페이지·EPSIS 육지/제주 재조회에서도 해당 실제가격을 확보하지 못했다. 평가 완료 0일, MAE·경제적 전향 성과 미확정이다. 다른 경로까지 모두 미공개라고 인증한 것은 아니다.
- 네 기록의 D-2 23시 입력 수신시각과 21개 피처를 원본 스냅샷에서 재계산해 일치 확인했다. 최대 입력 수신은 10월 15일 21:59:54 KST, 기준은 23시이며 실제 생성은 약 23:49이다. 정확히 23시 실행됐다고 주장하지 않는다.
- 사후 추가한 네 잔차 범위 주석은 생성시각을 별도로 기록한다. 2025Q3 시간대별 절대잔차 90분위 범위이며 조건부 90% 보장을 뜻하지 않는다. 원예측의 일부로 소급하거나 전향 표본 수를 늘리지 않는다.
- 실제 도착 시 기존 V12의 별도 평가 파일(MAE/RMSE/피크/F1/ramp)과 V13 연결시간 기준 EV 평가를 생성한다. 원예측은 수정하지 않는다. V11 D-1 연구 모델과 V12 D-2 모델을 구분한다.
- 공식 규정의 전일 17시 원칙은 회원 거래시스템의 통지 체계와 관련된다. 일반 공개 페이지의 정확한 최초 공개시각을 확정한 근거는 없다. 전일 22:04에 이미 다음 날 가격을 관측한 사례로 D-1 23시를 항상 유용한 선행 예측으로 표시할 수 없다. D-2도 모든 공개 경로보다 빠름을 증명하지 못한다.
- V11/V12 기존 작업은 `IgnoreNew`를 유지한다. V13 감사 전용 작업도 15분 간격, `IgnoreNew` 및 프로세스 잠금을 사용하며 네트워크 수집을 중복하지 않는다. 누락 구간과 성공 관측 간격을 표시하고 절전·종료 원인을 추정하지 않는다.
- V11 전체 작업은 외생변수 예측에 필요한 적격 수요/기상 입력이 없어 해당 단계가 실패했다. SMP·ASOS 수집 성공과 전체 작업 성공을 혼동하지 않는다. V13 상태에 실패 단계를 표시한다. V12 수동 갱신 및 V13 파이프라인은 성공했다.

## 급등 연구의 판단

V12의 30개 조건(28개 고유 선택 가격출력)을 재사용하고 같은 평가 정답에 추가 튜닝하지 않았다. **V13 신규 학습 실험은 0개**다. 입력 발표본이 없는 상태에서 알고리즘 수만 늘리지 않았다. 검증 상위 후보는 LightGBM 피크 가중, 검증 앙상블, ExtraTrees 피크 가중으로 유지한다.

|2025Q4 선택 검증|전체 MAE|150원 이상 MAE|피크 F1|
|---|---:|---:|---:|
|HGB 기준|13.3806|37.2443|0.1667|
|LightGBM 피크|13.2972|29.6959|0.1429|
|검증 앙상블|12.3976|36.8173|0.1429|
|ExtraTrees 피크|13.3170|32.2174|0.1053|

2026H1 사후 감사에서 앙상블 전체 MAE 10.7662는 기준 10.7951보다 약간 낮지만 피크 MAE는 34.2080 대 34.0600으로 악화했다. LGB 피크 MAE는 31.1836으로 감소했지만 전체 MAE 11.4040으로 악화했다. 이미 확인한 10월 1~15일 고가 6시간은 전 모델이 놓쳤다. 운영 모델 교체 근거가 부족하다.

150원 고정 기준은 검증 구간 양성 7시간으로 희소하다. 학습 전체 95분위 241.63원은 과거 고가격 체제에 좌우되어 현재 피크와 맞지 않는다. 당시 발표본 수요/기상·발전기 가용성·한계 발전원/연료 및 시간별 예비력 자료가 부족해 가격 급변의 인과 원인을 확정할 수 없다. 급등 위험 확률도 상수 사전확률보다 Brier가 나빠 운영 경고로 검증되지 않았다. `V13_INPUT_ELIGIBILITY.csv`에 변수별 적격성을 기록했다.

실제 D-2 입력은 SMP 이력과 달력 21개: hour_sin, hour_cos, dow_sin, dow_cos, month_sin, month_cos, weekend, daily, weekly, spread, origin_price, origin_lag1, origin_lag24, origin_lag168, mean24, std24, min24, max24, mean168, std168, change24. 역사 수요예측은 당시 발표본 여부 미확인, 기상예보 API는 마지막 확인 403으로 입력하지 않는다. ASOS는 관측이며 미래 예보로 대용하지 않는다. 발전기 정비/고장·공급전망·연료·예비력의 적격 발표 시계열은 아직 미확보다.

## EV 경제성

기존 2026H1 181일, 네 모델, 두 방식의 1,448개 충방전 결과를 재분석했다. 같은 배터리 60kWh, 초기30%, 출발80%, 충방전7kW, 효율 각각90%, SOC20~90%, 열화5원/배터리 처리kWh, 하루24시간 연결 가정이다. SMP 연동 가상 정산이며 소매요금이나 실증 V2G 판매수익이 아니다.

|모델|G2V 실제 순비용 평균|가상 V2G 실제 순비용 평균|G2V regret|V2G regret|예측 이익→실제 손실 날짜|
|---|---:|---:|---:|---:|---:|
|HGB|3389.76|3400.19|190.53|255.22|43/181|
|LightGBM 피크|3384.74|3411.69|185.51|266.72|69/181|
|검증 앙상블|3375.45|3387.38|176.23|242.41|47/181|
|ExtraTrees 피크|3374.22|3397.47|175.00|252.50|53/181|

동일 조건 즉시충전 평균3534.54원, 균등충전3854.66원이다. G2V/V2G regret은 각기 다른 사후 최적 제약 집합을 기준으로 하므로 비교 시 이를 구분한다. 724개 모델·날짜 중 212개 반전이 있지만 같은 날짜 네 모델은 독립 표본이 아니다. 2월18일 LightGBM 사례는 예측상 V2G 72.84원 절감이 실제로 G2V보다 939.15원 추가 비용이 됐다. 가격·전력·SOC 그래프는 로컬 `artifacts/v13/economics/reversal_example.png`, 전체 반전 CSV 및 동일조건 기준선 CSV로 재현한다. 이미 열람한 사후 자료이며 새 전향 성공이 아니다.

V13은 부분 시간 연결의 사후 최적 비교에 저장된 시작·종료시각을 적용한다. V12의 기존 평가는 이 경계를 생략할 수 있어 regret이 과대평가될 수 있었다. 기존 결과를 변경하지 않고 `V13_saved_connection_window` 별도 버전으로 평가한다. 연결시각이 누락된 부분 슬롯은 평가 부적격으로 남긴다. 기존 MILP의 SOC·전력·효율·동시충방전 금지 및 음수가격 처리를 유지한다.

## 실행과 검증

프로젝트 폴더에서 실행:

```powershell
..\.venv\Scripts\python.exe -m v13.service
..\.venv\Scripts\python.exe -m v13.economics
..\.venv\Scripts\python.exe -m streamlit run app_v13.py --server.address=127.0.0.1 --server.port=8503
..\.venv\Scripts\python.exe -m unittest discover -s tests
..\.venv\Scripts\python.exe -m scripts.smoke_v13
```

로컬 화면 `http://127.0.0.1:8503/`. 공식가격 우선/저장 예측 모드를 구분하고 수신시각·평가 대기·급등 한계·EV 입력·비용·SOC를 표시한다. 고급 제약 입력은 접을 수 있고 공유 ZIP만 다운로드한다. 비공개 ZIP 다운로드는 제공하지 않는다. 버튼 계산은 V13 별도 불변 의사결정으로 저장한다.

`GradprojectV13Audit` 등록 후 실제 예약 작업을 수동 시작해 종료 코드 0을 확인했다. 이 실행과 겹친 두 번째 수동 실행은 잠금으로 차단됐고 원본은 변경되지 않았다. 실제 8503 서버도 HTTP 200 `ok`를 확인했다. GitHub `/user` 인증 조회로 `parksiwon22`를 확인한 뒤 개발 브랜치만 Push한다.

전체 단위/회귀 테스트 **58개 통과**, AppTest의 실제 최적화 버튼 및 별도 HTTP 서버 실행 통과. 미래 수신시각 차단, 저장 피처 재계산, 사후 범위의 비소급, 부분 연결 oracle, 미도착 실제값 평가 보류, 중복 실행 잠금, 기존 V5/V11/V12/EV/ZIP 검증을 포함한다. 테스트가 생성한 V5 지표 파일은 원본 Git 바이트로 복구했다. 기존 V5/V11/V12 소스 및 공개 app의 diff가 없다. 로그는 로컬 artifacts에 보존한다.
