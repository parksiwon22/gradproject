# Streamlit 실행·졸업작품 시연 안내

## 실행 방법

프로젝트 폴더 `gradproject`에서 실행한다.

```powershell
..\.venv\Scripts\python.exe -m streamlit run app_v20.py
```

브라우저에서 `http://localhost:8501`을 연다. 다른 환경에서는 Python 3와 `requirements.txt`에 있는 Streamlit 및 프로젝트 의존성이 필요하다. 이 시연 경로는 보존된 로컬 예측·실제 SMP를 사용하므로 오늘 밤 예약작업이나 새 API 호출을 기다릴 필요가 없다.

### 화면 구성

- **SMP 예측·공식가격 비교:** V12~V18에 이미 저장된 같은 날짜의 예측과 공식 제공가격 비교
- **과거 예측 시연:** D+1/D+2/D+3 및 V5 92일, V20 42일 자료에서 과거 대상일을 선택해 실제·예측·기준선 SMP를 비교하고 EV 추천을 재생
- **EV 충전 추천:** 현재 보유한 공식 자료 또는 검증된 보존 예측에 대한 현재 조건의 계산
- **연구 예측 정확도:** 모델·예측기간별 MAE/RMSE, 시간대 오차, G2V regret와 vintage 주의사항
- **연구 결과·시스템 상태:** 발급 gate 및 자동 작업 상태

## 5분 시연 순서

1. 왼쪽 메뉴에서 **과거 예측 시연**을 선택한다.
2. 시연 자료 유형으로 **실제 저장 예측 (V11–V20)**, 예측 기간 **D+2**, 대상일 **2026-10-18**, 모델 **V12 LightGBM peak**를 선택한다.
3. 차트의 실제 SMP·저장 예측·발급시점 기준선을 비교한다. 이 모델은 시간별 급등 확률을 저장했으며, 선택한 기록에서 지원하는 경우 위험도 표를 보여준다.
4. 배터리 용량, 초기 SOC, 목표 SOC, 시작·출발 시각을 입력한다. G2V 추천 충전시간, 예측가격 비용, 실제 제공가격 기준 사후 비용/regret를 확인한다.
5. D+1 시연은 **V5 보존 92일 테스트**를 선택한다. D+3 시연은 **실제 저장 예측**에서 2026-10-19 V17 또는 2026-10-27 V20을 선택한다. V20의 42일 값은 실제 발급이 아니라 과거 재현으로 표시된다.
6. **연구 예측 정확도** 화면에서 V5 92일과 V20 42일 집단을 분리해 표와 그래프를 확인한다.

## 비교 해석 시 주의

- V5 92일 자체 테스트, 2026년 저장 발급 예측, V20 42일 과거 재현은 평가 기간과 생성 방식이 다르다. 다른 집단 간 숫자를 직접적인 성능 향상으로 말하지 않는다.
- D+2 2026-10-26은 발급 당시 실제 SMP 24시간을 이미 알고 있었으므로 사전예측 정확도 표본에서 제외됐다.
- 일부 오래된 예측은 기준 발급시각보다 늦게 저장됐거나 모델 잠금시각이 확인되지 않는다. 학생 발표에서는 “저장 예측의 사후 비교” 또는 “참고 백테스트”라고 표시한다.
- actual 그래프 가격은 보존된 공식 제공 SMP이며, 최종 정산 확정·사후 수정 통계 여부가 확인되지 않았다.
- EV 비용/Regret은 가상 SMP 기반 평가이며 실제 충전요금이나 실차 V2G 매출이 아니다. 기본 추천은 G2V다.
- 날씨·가격 위험 출력이 저장되지 않은 모델은 웹에서 “지원 출력 없음”으로 표시한다. 모델이 제공하지 않는 위험도를 임의로 만들지 않는다.

