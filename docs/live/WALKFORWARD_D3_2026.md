# 2026 D+3 SMP 시점 재현 및 EV 의사결정 결과

## 평가 범위

- 대상일 2026-01-01~2026-11-12, 총 316일. 완전한 24시간 실제 가격 벡터가 있었고, 제외일은 0일입니다.
- D+3 예측은 고정 파라미터 HGB 잔차 모델과 5% seasonal anchor 혼합입니다. Anchor는 7/14/21/28일 전 같은 시간 SMP 중앙값입니다. 모델은 매주 월요일 00:00 KST 기준으로 과거 라벨만 사용해 재학습했습니다.
- 가격 예측 벡터와 MAE/RMSE는 이 regret 수정에서 변경하지 않았습니다.
- 모든 행은 시간순 historical replay입니다. 과거 SMP `first_seen` 시각과 당시 공개 가능 여부가 입증되지 않았으므로 실제 운영 발급 성능이 아닙니다. 23시 가격 가용성도 별도로 확인되지 않았습니다. 대상일 가격은 EPSIS 저장 육지 SMP이며, 최종 정산 확정 여부도 독립 확인되지 않았습니다.

## 가격 정확도와 G2V 사후 regret

G2V regret은 다음 방식으로 다시 계산했습니다.

`고정된 예측 기반 충전계획을 실제 SMP로 평가한 비용 − 실제 SMP를 알고 선택한 최적 충전계획의 실제 비용`

각 계획에 같은 충전 효율과 열화비용을 적용했습니다. 차량 조건은 60kWh, 초기 SOC 30%, 목표 80%, 최소/최대 SOC 20/90%, 충전 7kW, 효율 90%, 배터리 에너지 기준 열화비용 5원/kWh, 24시간 연결입니다.

| 2026 D+3 historical replay | 일수 | MAE (원/kWh) | RMSE (원/kWh) | 평균 G2V regret (원/일) |
|---|---:|---:|---:|---:|
| HGB residual + 5% seasonal anchor | 316 | 10.903 | 16.392 | 122.32 |
| seasonal anchor 단독 | 316 | 12.938 | 20.078 | 154.27 |

이 EV 조건에서 HGB 혼합은 anchor보다 평균 G2V regret이 20.7% 낮았습니다. 이 결과는 가격 오차 개선이 해당 고정 차량·비용 가정에서의 충전 의사결정 개선과 함께 관찰됐다는 뜻입니다. 다른 차량 조건이나 소매 전기요금으로 일반화할 수 없습니다.

이전 웹/보고서의 187.28원, 145.86원, 28.4%는 예측 기반 계획 비용을 예측가격으로 평가한 잘못된 regret 산식의 결과여서 철회하고 새 결론에 사용하지 않습니다. MAE, RMSE 및 저장 예측 곡선은 그대로입니다.

## 가상 V2G 시나리오

동일한 316개 예측/실제 벡터와 차량 조건에서 Python `v12.ev`의 MILP 최적화와 사후 점수를 사용했습니다. 판매 정산은 가정상 SMP의 100%로 두고, 열화비용 및 효율은 G2V와 동일하게 적용했습니다.

| 항목 | 평균 |
|---|---:|
| 예측 기반 가상 V2G 계획의 실제 SMP 순비용 | 3,376.80원/일 |
| 실제 SMP를 알고 고른 V2G oracle 순비용 | 3,172.47원/일 |
| V2G regret | 204.34원/일 |
| 평균 수출량 | 2.462kWh/일 |
| 예측 기반 G2V 대비 실제 SMP 순비용 차이 | V2G가 평균 25.81원/일 낮음 |

V2G는 316일 중 93일에서 예측 기반 V2G의 실현 순비용이 G2V보다 낮았고, 50일은 더 높았으며 173일은 같은 수준(수치 허용오차 0.01원 이내)이었습니다. 따라서 V2G가 항상 유리하다고 해석하지 않습니다. 100% SMP 연동 판매정산은 공개 웹 시뮬레이션 가정입니다. 국내 시장 참여 자격, 실제 소매 구매요금, 판매 정산제도 또는 차량/충전기 수익을 확인한 값이 아닙니다.

공개 웹에서 기본 EV 조건으로 이 2026 재현 레코드를 선택하면 Python MILP가 저장한 V2G 계획과 oracle 계획을 사용해 백테스트 수치와 일치시킵니다. 다른 사용자 입력은 브라우저에서 재계산하며 V2G에는 0.1kWh 상태 격자 동적계획법을 씁니다.

## 기상 변수 검토

현재 HGB 예측은 EPSIS 육지 SMP의 과거 lag/rolling 값과 달력 변수만 사용합니다. 수요, 기상관측 또는 대상일 기상예보는 입력되지 않습니다.

KMA 단기예보 API는 발표 vintage와 시간별 유효시각을 저장해 예측 원점 이전의 예보만 feature로 쓸 수 있도록 별도 수집기를 추가했습니다. 서울 단일 지점 대신 강릉·서울·대전·대구·광주·부산의 6개 육지 격자/ASOS 지점 참조를 정의했습니다. 이 집합은 지리적으로 분산된 탐색용이며 부하가중 전국 대표값으로 검증된 지점 조합이 아닙니다. 관측 ASOS는 별도 자료형이며, 과거 D+3 예보의 대체 입력으로 쓰지 않습니다.

이번 환경에는 data.go.kr 서비스 키가 없어 단기예보 API 실수집은 보류했습니다. 기존 API Hub 접근 기록에서는 ASOS 기간 관측 요청은 성공했으나, 최근/과거 단기예보 요청은 HTTP 403 서비스 신청/승인 제한에 걸렸습니다. 기존 관측자료는 예보 vintage가 아니므로 2026 historical replay에 병합하지 않았습니다. 따라서 기상 피처는 모델에 반영되지 않았고, 기상 확장 모델의 2026년 MAE/RMSE/시간별 오차/regret 평가는 수행하지 않았습니다.

수집기는 `KMA_DATA_GO_KR_SERVICE_KEY` 또는 `KMA_SERVICE_KEY` 환경변수만 읽고 키와 응답 본문을 로그/파일에 기록하지 않습니다. 키가 없으면 안전하게 `deferred`를 반환합니다. 한 번의 예보 수집은 6개 권역 격자별 요청 6회입니다. 공공데이터포털은 이 API의 비용을 무료로 표시하지만, 이 환경에서 서비스 키 승인 및 계정별 호출 할당량은 검증하지 못했습니다. 단기예보는 발표 vintage에 따라 글피까지 시간별 상세값을 제공한다고 명시되어 있습니다. 수집 완료 응답시각을 각 행에 기록해, 기준시각을 넘긴 수신은 과거 원점 입력으로 선택되지 않습니다. ASOS 결측은 보간하지 않습니다.

자세한 스키마와 인증/호출 한계는 [기상 데이터 메모](./weather/README.md)를 참고하세요. 공식 안내: [기상청 단기예보 API](https://www.data.go.kr/data/15084084/openapi.do), [기상청 ASOS API](https://www.data.go.kr/data/15139432/openapi.do), [기상청 API Hub](https://apihub.kma.go.kr/).
