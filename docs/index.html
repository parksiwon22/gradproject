피크 예측도 검증

급등 가중 LightGBM과 계절별 피크 전용 모델을 시험했으나 전체 MAE와 충전 판단 성능이 일관되게 개선되지 않아 최종 후보에서 제외했습니다.

03

충전 의사결정에 활용

가격을 예측하는 것에서 끝나지 않고, 같은 차량 조건에서 실제 SMP 기준 충전 비용과 사후 최적 계획의 차이를 검증합니다.

사용 전 꼭 알아주세요

이 웹은 V20에 연결된 최종 연구 fold 예측 데이터를 불러오는 공개 연구 시연입니다. 새 미래 가격을 예측하지 않으며 실시간 발급, 공식 발급 게이트, 로컬 데이터베이스에 연결하지 않습니다. 실제 SMP는 검증 대상일의 과거 가격이며, 당시의 최초 공개 시각과 모델 가용성은 검증되지 않았습니다. 충전 비용은 도매 SMP를 사용하는 가상 정산으로 가정용 충전요금이나 V2G 수익이 아닙니다. 충전 계획은 서로 떨어진 시간대에 나누어 충전할 수 있습니다.
