# V11 기상청 API허브 시간 관측 후속 실험

생성: 2026-10-15T14:33:04.381075+00:00 · 기준 커밋 1fa7ae7. 기존 V5/main/기존 예측·수집 이력 보존.

ASOS 기간 API 추가 신청 후 실제 자료 수신에 성공했다. Windows 사용자 환경변수 키는 읽히지만 시작 당시 프로세스 환경에는 없었다. 기존 안전한 사용자 환경변수 읽기 함수를 재사용했고 키·인증 URL·오류 응답 원문은 출력하지 않았다.

단기 격자예보는 추가 신청 후에도 최신 날짜와 공식 과거 예제에서 HTTP403 및 활용신청·승인 안내를 반환했다. 키 자체의 전면 오류는 ASOS 성공으로 구분되지만, 격자예보의 승인 반영 여부와 세부 권한은 확정할 수 없다. ASOS 단일시각에서 발생한504는 상위 서비스 장애로 분류한다. 데이터포털 serviceKey와 API허브 authKey를 혼용하지 않았다.

| 2023 | 61,286 | 34 |

총 232,327개 행. 서울108·대전133·대구143·광주156·부산159·강릉105·제주184. 2023~2025 전년과2026-10-15 21:00 KST까지 요청했다. 관측소 운영기간은 별도로 보증하지 않으며 응답에서 빠진 시간을 복구한 것으로 표시하지 않는다. 제주 기상은 보조 설명변수이며 제주 SMP와 육지 SMP를 혼합하지 않는다.

기온·습도·풍속·일사(SI, MJ/m²)·일조(SS, 시간)·강수(RN, mm) 원본 필드를 저장했다. TM은 KST 관측시각이다. RN_DAY 누적값을 시간 강수로 변환하지 않았다. RN의 세부 집계 구간을 추가 검증하기 전에는 원본 필드 정의를 유지한다. 야간 일사/일조의 결측 및 무강수/결측을 나타낼 수 있는 원본 플래그를 0으로 바꾸지 않았다. 독립 QC 플래그가 없는 응답의 결측 코드를 보존했고 실제 영하9도는 결측 처리하지 않았다.

변수별 결측률은 `V11_KMA_HOURLY_INVENTORY.csv`에 관측소·연도별로 기록했다. 이 비율은 반환된 행을 분모로 하므로 행 자체 부재 건수를 별도 제공한다. 원본 46개 월 구간, SHA256·요청 인자·최초 수신시각과 정정본은 비공개 artifacts/v11/kma_apihub/period_raw/에 보존한다. 정규화 CSV는 기존 일별 기상과 분리했다.

## 예보 자료와 가용성

2023~2026 과거 발표 격자예보 원본은 이번 작업에서 확보하지 못했다. C(SMP+당시 기상예보), D(SMP+수요예측+당시 기상예보)는 미실행이다. 관측을 예보처럼 대체하지 않았다. 기존 공식 공개 웹에서 수신했던 최신 발표 예보와 관측 대용값으로 학습한 미검증 시나리오는 보존하되 기본 모델로 승격하지 않았다. 기존 수요예측 값은 실제 KPX 예측이지만 역사 발표시각·당시 판본은 미확인이다.

## 실제 모델 비교

고정 HGB(250회,31잎,학습률0.05,seed42,시간순 검증). 학습2023~2026Q1, 검증2026Q2, 새 고정 평가2026-10-01~15. 2026Q3를 다시 튜닝·점수 계산하지 않았다. 4개 모델은 같은 완전24시간 날짜를 사용한다. 학습/검증/평가 행 수: {'train': 27048, 'validation': 2184, 'test': 360}. 관측소별 기온·습도·풍속이 빠진 날짜는 모든 비교 모델에서 같이 제외하고, 나머지 관측 결측은 HGB가 직접 처리한다.

| 모델 | 입력 수 | MAE | 고가 MAE | 고가 F1 | EV regret |
|---|---:|---:|---:|---:|---:|
| A SMP 단독 | 21 | 6.6514 | 62.2122 | 0.0000 | 5.4526 |
| B +수요예측(발표본 미확인) | 22 | 6.5066 | 59.2387 | 0.0000 | 5.2243 |
| +48시간 지연 ASOS 관측 | 63 | 6.4683 | 62.1124 | 0.0000 | 5.0484 |
| +수요예측+지연 ASOS 관측 | 64 | 6.7388 | 61.3978 | 0.0000 | 5.5041 |

가격 단위 원/kWh. EV regret는 가상 SMP 연동1kW·연속2/3/4/5/6/8시간 시나리오의 평균 비용 차이다. 실제 개인 충전요금/V2G 수익이 아니다. 전체 RMSE/R², 고가 Bias·Precision·Recall·허위 경보, 최고가격/피크 시각, 상승·하락 ramp, EV 비용·선택 일치도는 METRICS.csv에 있다.

고가 기준150원/kWh인 평가6시간을 모든 모델이 탐지하지 못해 F1=0이다. 짧은10월 평가에서 관측 추가만으로 전체 MAE는 줄었으나 고가 성능 개선은 입증되지 않았고 수요+관측 결합은 전체 MAE도 악화됐다. 기존2026Q3 결과10.8617/10.3500과 기간이 달라 숫자를 직접 비교하지 않는다. 운영 모델 교체와 기존 V5 교체를 수행하지 않았다.

## 전향 기록·자동화·검증

새 관측 모델 전향 기록은 목표시각-48시간 관측과 SMP의 실제 수신시각을 D-1 23시 기준으로 제한한다. 최초 수집이 기준시각 이후라면 예측을 만들지 않고 불변 skip 기록만 남긴다. 이번 첫 실행은 이 조건 때문에 skip됐다. 생성시각·기준시각·대상일·모델 해시·공식 SMP 기확보 여부와 기상/수요 예보 사용 여부를 기록한다. 예보를 학습한 새 운영 모델의 미래 예측은 아직 제공하지 못했다.

기존 Windows GradprojectV11Local 작업(매시간 및23:05)을 재사용한다. 승인된 기간 API로 최근72시간을 재조회해 정정을 별도 원본으로 보존한다. 자동 재학습·승격·업로드는 없다. 실패하면 기존 데이터와 예측을 보존한다. 기존 Streamlit에 수집 현황과 전향 기록만 추가했고 EV 추천의 기본 모델은 유지했다.

28개 V5/V11/기상청 회귀·키 비노출·미래 관측/늦게 수신한 정정본 차단 테스트 통과. 최초 제한 환경의 임시 디렉터리 권한 실패는 실제 로컬 환경 재실행에서 통과했다. 실제 Streamlit HTTP health 통과. 2026-10-15 23:31 KST 전체 파이프라인7단계 모두 exit_code0을 확인했고 비공개 artifacts/v11/pipeline_status.json에 기록했다.
