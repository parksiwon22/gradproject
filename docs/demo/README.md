# 날짜 선택형 예측·충전 추천

첫 화면에서 예측 시작일을 선택합니다. 저장된 2025년 검증182개 발행일과 2026년11월20~22일 사전예측을 구분합니다. 선택한 날짜의 실제 72개 예측을 사용하며 임의 날짜변경/새 예측 생성은 하지 않습니다.

2025년은 실제값을 비교하고 당시기준시각으로 충전시뮬레이션합니다. 2026년은 기존20:05 사전계산본을 표시하며 실제값은미연결,5개발전량입력은대체조건입니다. 재발행작업은취소상태를유지합니다.

선택한기간에맞춰충전날짜·추천·CSV가갱신됩니다. 실제자료가없는날짜는목록에넣지않습니다. 과거재생과6개월/월별그래프는별도탭에유지합니다.

- 과거 예측 재생: 기존 발행일·모델·72시간 선택 기능 유지.
