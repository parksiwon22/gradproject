# 날짜 선택형 SMP 예측·EV 충전 추천

첫 화면에서 예측 시작일을 선택하면 해당72시간 가격과충전추천을표시합니다. 자료가없는날짜를임의로만들지않습니다.

## 날짜 선택과 충전 날씨

2026년11월1~30일은자료유무와관계없이모두선택할수있습니다. 실제예측이없는날짜에는준비안내와준비된예측으로이동하는버튼만표시하고가격이나충전결과를만들지않습니다. 선택만으로모델추론/수집작업이실행되는것은아닙니다.

충전날씨는기상예보가아닌예측SMP의상대가격지수입니다. 해당일24시간중앙값이하☀️맑음,초과☁️흐림이며모든가격이같으면가격차이없음으로표시합니다. 시간카드와충전추천표에같은지수를사용합니다. 날씨선택과그래프D+1~D+3선택을연동합니다. 추천최적화는입력한가능시간안에서실행하므로하루전체상대지수와구분합니다.

## 선택 가능한 자료

- **2025년 과거 검증**: 실제저장된E3 결과182개발행일. SARIMAX40%+주간기준선60%를표시하고실제SMP와비교합니다. 당시예측기준시각으로충전시뮬레이션합니다.
- **2026년11월20~22일 사전예측**: 11월19일20:05에실제계산한72개가격. 예정기준시각23시와실제계산시각을구분합니다. 실제값/오차는미연결이며LNG·석탄·원자력·태양광·풍력최근입력은대체조건입니다. 국내LNG는10월값입니다. 23시재발행은취소상태를유지하며이조회기능이새추론이나재발행을실행하지않습니다.

실제값이없는구간에0을그리거나오차를만들지않습니다. 날짜변경시그래프·날짜버튼·충전시작/종료·추천·CSV를갱신하고빈선택으로돌아가면이전결과를숨깁니다.

## 기존 과거 재생

발행일·모델·72시간선택기능은별도탭에유지합니다. 하반기전체4416시간및7~12월선택그래프를제공합니다. 중복대상은가장최근발행예측을사용하고마지막이틀은D+2/D+3을연결합니다. 그래프구간MAE와원래13104행성능은다른집계입니다. 과거평가는발전량대체·동월LNG조건이있는후속재평가입니다.

## 충전 추천

배터리용량·현재/목표SOC·출력·효율·충전가능시작/종료를입력합니다. 필요계통전력량을저가시간부터배분하고마지막시간은부분배분합니다. 기간내공급량이부족하면목표달성으로표시하지않습니다. 2025년은당시기준,2026년은현재이후시간을사용합니다. 비용은SMP×계통전력량의가상비용이며실제충전요금/절감액과구분합니다.

## 오프라인 및 검증

`downloads/smp72-offline.html`을다운로드해Chrome으로엽니다. 날짜선택·두종류예측·충전추천·6개월/월별그래프가포함됩니다. 생성:`python scripts/build_smp72_offline.py`.

검사:`python -m unittest discover -s tests/smp72_demo -v`, `node --test tests/smp72_demo/charging.test.cjs`. 브라우저에서183개블록선택·실제값유무·충전날짜·모바일·오프라인을검증했습니다.
